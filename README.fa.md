# دستیار خبری (News Assistant)

[English](./README.md)

یک صفحه‌ی مستقل که کاربر می‌تونه در هر موضوعی سوال کنه («چه خبر از X؟») و یک پاسخ مستقیم یک‌خطی به‌همراه مرتبط‌ترین اخبار ایسنا (از فایل `news.json` پروژه‌ی [isnabot](../isnabot)) دریافت کنه.

قراره به‌عنوان یک زیرپوشه به سایت موجود اضافه بشه، مثلاً: `yourdomain.com/ai/news-assistant/`

## نحوه‌ی کار

۱. کاربر سوالش رو توی باکس جست‌وجو می‌نویسه.
۲. `api.php` ابتدا با یه فیلتر کلمه‌کلیدی محلی (بدون هوش مصنوعی)، اخبار امروزِ کش‌شده‌ی ایسنا (از `news.json` پروژه‌ی isnabot) رو به یه فهرست کوتاه محدود می‌کنه تا درخواست سبک و سریع بمونه.
۳. همون فهرست کوتاه + سوال کاربر به یک مدل زبانی (از طریق [OpenRouter](https://openrouter.ai)) فرستاده می‌شه و این خروجی رو برمی‌گردونه:
   - یک پاسخ مستقیم و یک‌خطی به سوال
   - حداکثر ۴ خبر منبع، هرکدام با یک توضیح یک‌خطی درباره‌ی ارتباطش
۴. صفحه اول پاسخ رو نشون می‌ده، بعد کارت‌های منبع رو زیرش، به‌همراه توضیحی درباره‌ی تازگی داده‌ها (چون کش ایسنا هر شب نیمه‌شب پاک می‌شه، نتایج «از ساعت ۰۰:۰۰ امروز تا کنون» رو پوشش می‌دن).

بدون دیتابیس برداری (vector database)، بدون embedding — فقط یک پیش‌فیلتر سبک کلمه‌کلیدی + یک فراخوانی به مدل زبانی. همین باعث می‌شه راحت روی یه هاست اشتراکی/سی‌پنل معمولی (فقط با PHP و curl) قابل اجرا باشه.

## راه‌اندازی

۱. فایل `config.example.php` رو کپی کن به `config.php`:
   ```
   cp config.example.php config.php
   ```
۲. `config.php` رو ویرایش کن:
   - `OPENROUTER_API_KEY` — یه کلید رایگان از [openrouter.ai](https://openrouter.ai/keys) بگیر
   - `OPENROUTER_MODEL` — پیش‌فرض `openrouter/free` (روتر خودکار رایگان OpenRouter). می‌تونی برای کیفیت بهتر روی یه مدل پولی مثل `openai/gpt-4o` بذاریش.
   - `SITE_URL` / `SITE_NAME` — برای هدرهای `HTTP-Referer` و `X-Title` که OpenRouter توصیه می‌کنه.
   - `ISNABOT_NEWS_FILE` — مسیر فایل `data/news.json` پروژه‌ی isnabot روی سرورت. پیش‌فرض یه پوشه‌ی هم‌سطح (`../../isnabot/data/news.json`) در نظر گرفته شده؛ اگه مسیر واقعی فرق داره اصلاحش کن.
۳. پوشه رو روی هاستت آپلود کن (مثلاً به‌عنوان زیرپوشه‌ی سایت اصلی).
۴. فایل `config.php` در `.gitignore` قرار داره — هیچ‌وقت commit‌اش نکن، چون کلید API توشه.

## پیش‌نیازها

- PHP با curl فعال
- دسترسی خروجی HTTPS به `openrouter.ai` از روی هاست
- یک نمونه‌ی در حال اجرای [isnabot](../isnabot) که `news.json` تولید کنه

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.php` | خود صفحه (باکس جست‌وجو، نمایش نتایج، هم‌راستا با تم سایت اصلی) |
| `api.php` | بک‌اند: پیش‌فیلتر کلمه‌کلیدی + فراخوانی OpenRouter + پاسخ JSON |
| `config.example.php` | نمونه‌ی تنظیمات — کپی کن به `config.php` و مقادیر خودت رو بذار |
